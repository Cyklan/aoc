# AoC

A small Advent of Code shell (and my solutions). My current goal is to solve all AoC puzzles.

Current progress: 0 solved

## Running for yourself

If no files for a day have been created yet, the first execution will create a input and solution file. Subsequent executions will run the silver solution unless specified otherwise.

### CLI Args

| Long form | Short Form | Default |
|-----------|------------|---------|
| --days    | -d         | Todays day |
| --year    | -y         | Current year |
| --level   | -l         | silver  |
